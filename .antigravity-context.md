# Contexto Técnico: automacao-chamados-sti

## Ambiente e Infraestrutura

- **Ambiente Host:** Windows 11
- **Gerenciador de Pacotes:** Python (3.11.9)
- **Banco de Dados:** SQLite

## Estrutura de Diretórios

- `01 - Dados Brutos`: Arquivos brutos do OTRS e CitSmart em Excel.
- `02 - Dados tratados`: Arquivos de saída do pré-processamento em Excel.
- `03 - Dados prontos`: Dados passados depois do `tag_classifier.py` em Excel.
- `models`: Os arquivos joblib para treinamento do GridSearch.
- `debug_logs`: Arquivos de log gerados durante a execução dos scripts.
- `custom_select_component`: Componente de seleção personalizado, com interface mais amigável em HTML.
- `old_scripts/`: Contém scripts legados e não utilizados atualmente.
- `src/`: Contém todos os códigos-fonte, scrapers, módulos de banco de dados e utilitários.
- `tests/`: Contém os scripts de testes unitários e rascunhos de testes do Streamlit.

## Scripts de Execução

- `orquestrador.py`: Script mestre focado exclusivamente na esteira de chamados de TI (Coleta OTRS, Coleta CitSmart, Pré-processamento, Classificação de TAGs por IA).
- `dashboard.py`: Painel de visualização Streamlit e mapa de localização (Leaflet).
- `src/citsmart_scraper.py`: Usado para raspar dados do CitSmart.
- `src/config.py`: Configurações globais e utilitários compartilhados.
- `src/database.py`: Funções de interface e migrações do SQLite.
- `src/manual_entries_TEMPLATE.py`: Template de entradas manuais.
- `src/manual_entries.py`: Entradas manuais de dados para popular informações de salas.
- `src/otrs_scraper.py`: Usado para raspar dados do OTRS.
- `src/preprocess_chamados.py`: Pré-processamento e normalização dos chamados brutos.
- `src/salvar_senha.py`: Usado para persistir credenciais locais do AD no cofre do Windows (keyring).
- `src/sync_master.py`: Sincronizador de dados legados com planilhas.
- `src/tag_classifier.py`: Treinamento e classificação de TAGs por IA (NLP spaCy e Machine Learning).
- `src/sync_donations.py`: Worker de segundo plano para sincronização da planilha de doações e redistribuição (mini-orquestrador que usa cópia temporária `shutil` para contornar o Lock do Excel no Windows).
- `src/sync_fiscalizacao.py`: Worker de segundo plano para sincronização da planilha de fiscalização de contratos SAJ (mini-orquestrador que usa cópia temporária `shutil` para contornar o Lock do Excel no Windows).
- `src/sync_garantia.py`: Worker de segundo plano para sincronização da planilha de controle de garantias (mini-orquestrador que usa cópia temporária `shutil` para contornar o Lock do Excel no Windows).
- `src/components/subtabs.py`: Componente de navegação por sub-abas com sincronização de query parameters na URL.
- `src/components/calendar.py`: Componente mestre centralizado de calendário (FullCalendar v6, Modal Dinâmico Inteligente com Título integral, TAG e sanfonas de acompanhamentos para chamados, temas claro/escuro e abas vermelhas).
- `src/components/status_banner.py`: Gerenciador de logs e status universal de robôs com auto-refresh em tempo real (`@st.fragment`).
- `src/ramais_scraper.py`: Robô autônomo para autenticação na Intranet MPMS, download e extração em memória via pdfplumber da Lista Telefônica de Ramais do Interior e Capital/PGJ.
- `src/unidades_scraper.py`: Coleta informações de promotorias e procuradorias no portal do MP e persiste na tabela `unidades` do SQLite com suporte a lock_file.
- `src/tabs/links_faqs.py`: Módulo da aba de FAQs, Tutoriais do SharePoint, Vídeos FAQ, Links Úteis e Galeria de Imagens FAQ (organização por pasta/tutorial, visualizador em formato de carrossel modal `@st.dialog` com ajuste de proporção, navegação `⬅️`/`➡️` e atalho nativo no Windows).
- `src/tabs/calendario_geral.py`: Módulo da aba do Calendário Geral Unificado (consumindo o componente mestre calendar.py).
- `src/tabs/unidades.py`: Módulo da aba do Catálogo de Unidades do MPMS e Lista de Ramais Telefônicos (relação unificada com Origem, modal interativo `@st.dialog` para detalhes/edição/exclusão de manuais e accordions de logs em segundo plano).
- `src/migrate_manual_entries.py`: Script utilitário para migração das entradas manuais de unidades para o SQLite.
- `src/converter_pdf.py`: Script utilitário para converter plantas em PDF para formato de imagem PNG.
- `tests/test_app.py`: Testes unitários de pré-processamento, regras de negócio e scraping.
- `tests/scratch_test_st.py`: Script de rascunho temporário do Streamlit.

## Diretrizes de Geração de Código e Formatação

1. **Fim de Linha:** Forçar sempre `LF` (\n) em todos os arquivos.
2. **Estilo de Código:** Aspas simples (`singleQuote: true`), recuo/tabulação de 2 espaços.

## RESTRIÇÃO CRÍTICA PARA ECONOMIA DE TOKENS

1. **PROIBIDO executar terminais:** A IA não deve disparar comandos ou scripts de forma automática.
2. **Apenas texto de comando:** Forneça estritamente os comandos em blocos de código markdown. O desenvolvedor os executará manualmente no terminal do WSL e devolverá as saídas no chat quando necessário.
3. **Respostas Diretas:** Sem introduções ou explicações longas. Vá direto aos dados concretos e códigos limpos.
