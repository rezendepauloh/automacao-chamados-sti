# Contexto Técnico: automacao-chamados-sti

## Ambiente e Infraestrutura

- **Ambientes Suportados:** Containers Docker (WSL Ubuntu e Red Hat UBI 9) com inicializadores no Windows (`00-iniciar.cmd`) e Linux (`00-iniciar.sh`)
- **Gerenciador de Infraestrutura:** Docker Compose (100% em containers, sem dependência de `venv` local)
- **Banco de Dados:** SQLite (`chamados.db` centralizado) com suporte híbrido a PostgreSQL

## Estrutura de Diretórios e Containerização

- `01 - Dados Brutos`: Arquivos brutos do OTRS e CitSmart em Excel.
- `02 - Dados tratados`: Arquivos de saída do pré-processamento em Excel.
- `03 - Dados prontos`: Dados passados depois do `tag_classifier.py` em Excel.
- `models`: Os arquivos joblib para treinamento do GridSearch.
- `debug_logs`: Arquivos de log gerados durante a execução dos scripts.
- `custom_select_component`: Componente de seleção personalizado em HTML.
- `old_scripts/`: Contém scripts legados.
- `src/`: Códigos-fonte, scrapers, DAOs do SQLite e utilitários.
- `tests/`: Testes unitários integrados.
- `Dockerfile`: Imagem container otimizada para WSL/Linux Debian (`python:3.11-slim`) com Playwright/Chromium integrado.
- `Dockerfile-MP-RedHat`: Imagem para ambiente Red Hat Enterprise Linux (UBI 9).
- `docker-compose.yml`: Orquestrador universal com persistência de volumes e live-reload sem necessidade de `venv` local.
- `.dockerignore`: Filtro de exclusão de artefatos temporários no build Docker.

## Scripts de Inicialização e Execução

- `00-iniciar.sh`: Script de inicialização no WSL/Linux (sobe o container via Docker Compose e gera QR Code para celular/tablet).
- `sistema-bancada.desktop`: Atalho para lançador do Linux Desktop.
- `00-iniciar.cmd`: Script de inicialização nativo no Windows.
- `init.py`: Script central de inicialização Python (configura IP, exibe banner colorido com QR Code e executa o Streamlit).
- `orquestrador.py`: Script mestre da esteira de chamados de TI (Coleta OTRS, CitSmart, Pré-processamento, TAGs IA).
- `dashboard.py`: Painel de visualização Streamlit e mapa Leaflet.
- `src/database/`: Camada modular DAO do SQLite (`connection.py`, `tickets_db.py`, `ramais_db.py`, `map_db.py`, `donations_db.py`, `plantoes_db.py`, `notifications_db.py`, `impressoras_db.py`, `central_db.py`, `garantia_db.py`, `events_db.py`, `unidades_db.py`, `fiscalizacao_db.py`).
- `src/scrapers/`: Scrapers e bots (`citsmart_scraper.py`, `otrs_scraper.py`, `oxe_scraper.py`, `papercut_scraper.py`, `plantoes_scraper.py`, `ramais_scraper.py`, `unidades_scraper.py`, `faq_scraper.py`).
- `src/syncs/`: Workers de sincronização em segundo plano.
- `src/components/`: Componentes reutilizáveis de interface (`header.py`, `subtabs.py`, `calendar.py`, `pagination.py`, `status_banner.py`).
- `src/scripts_powershell/`: Automação PowerShell remota (`Analisador.ps1`, `GeradorHtml.ps1`, `LimpezaEstacao.ps1`, `RemoverUsuariosLocais.ps1`).

## Comandos de Inicialização e Permissões no WSL

Para preparar e rodar os atalhos e scripts no WSL:
```bash
chmod +x 00-iniciar.sh sistema-bancada.desktop
gio set sistema-bancada.desktop metadata::trusted true 2>/dev/null || true
```

## Diretrizes de Interface e Compatibilidade Streamlit

1. **Parâmetro de Largura:** Utilizar estritamente `width='stretch'` para componentes responsivos de largura total (substituindo `use_container_width=True`).
2. **Componentes HTML:** Utilizar `st.components.v1.html(...)` para iframes HTML customizados.

## Diretrizes de Geração de Código e Formatação

1. **Fim de Linha:** Forçar sempre `LF` (\n) em todos os arquivos.
2. **Estilo de Código:** Aspas simples (`singleQuote: true`), recuo/tabulação de 2 espaços.

## RESTRIÇÃO CRÍTICA PARA ECONOMIA DE TOKENS

1. **PROIBIDO executar terminais:** A IA não deve disparar comandos ou scripts de forma automática.
2. **Apenas texto de comando:** Forneça estritamente os comandos em blocos de código markdown. O desenvolvedor os executará manualmente no terminal do WSL e devolverá as saídas no chat quando necessário.
3. **Respostas Diretas:** Sem introduções ou explicações longas. Vá direto aos dados concretos e códigos limpos.
